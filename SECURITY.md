# Security Policy

## Supported version

Security fixes are made against the latest version of the `main` branch.

## Reporting a vulnerability

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/pihlonme/GadgetBuddy-Studio-Ai/security/advisories/new).

Do not open a public issue or include real API keys, credentials, personal data, or exploit material in public discussions.

Include, without real credentials:

- a clear description of the issue;
- the affected version or commit;
- the expected security impact;
- minimal reproduction steps or a proof of concept; and
- any known mitigations.

If a credential may have been exposed, revoke or rotate it before submitting the report. The project will acknowledge the report, coordinate validation and remediation privately, and disclose details only when it is safe to do so. No fixed response-time guarantee is currently offered.

## Scope

Reports may cover source code, build and CI configuration, or GadgetBuddy's AI-provider credential boundaries. Vulnerabilities in third-party products or services should be reported directly to the relevant provider unless GadgetBuddy's integration causes the issue.
